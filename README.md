## Descripción

Este repositorio contiene el desarrollo del Taller 1 de Python,
correspondiente a la asignatura Electiva de Robótica.

El taller aborda diferentes conceptos de programación y su aplicación
a problemas relacionados con robótica, incluyendo operaciones con
vectores y matrices, coordenadas, cálculos matemáticos, interacción
por consola y representación gráfica.
